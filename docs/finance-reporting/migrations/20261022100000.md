# 20261022100000_reports_foundation

A new schema `reports` with two tables, for the shared report controls (DEV-455):

- `reports.saved_filters`: each person's last-used filters per report (one row each), and filters they save
  under a name. Deleted with the person.
- `reports.access_log`: who opened or exported which report, when, with which filters and how many rows
  (BRD §6.9 note). Append-only: a trigger refuses UPDATE, DELETE and TRUNCATE. The person is not a foreign
  key, so deleting a user is never blocked.

Server-only, like `fsm` and `finance`. No report data is stored. Nothing on live `main` reads it. No
dependency on earlier migrations except `public.user_profile`.

Tested on the harness: one last-used row per person and report; saved names unique per report regardless
of case; a saved row needs a name; the log refuses changes and deletion; deleting a user removes their
filters and keeps their log rows; server-only grants.

## Pre-check (expect `f`)

```sql
select exists (select 1 from pg_namespace where nspname = 'reports') as reports_schema_exists;
```

## Apply

1. The file in the SQL editor.
2. **Project Settings → API → Exposed schemas: add `reports`** (as for `fsm` and `finance`), then save.

## Post-check (expect one row: `t, t, t, t, f, f`)

```sql
select to_regclass('reports.saved_filters') is not null                       as filters_table,
       to_regclass('reports.access_log') is not null                          as log_table,
       has_table_privilege('service_role', 'reports.saved_filters', 'INSERT') as server_writes_filters,
       has_table_privilege('service_role', 'reports.access_log', 'INSERT')    as server_writes_log,
       has_table_privilege('service_role', 'reports.access_log', 'UPDATE')    as server_updates_log,
       has_schema_privilege('anon', 'reports', 'USAGE')                       as anon_uses_schema;
```

## Rollback

[`20261022100000_rollback.sql`](20261022100000_rollback.sql): drops the schema. Saved filters and the access
log are lost; no report figure is (they are computed).
