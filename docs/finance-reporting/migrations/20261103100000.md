# 20261103100000_finance_query_threads

Queries become a comment thread (2 Nov). Finance raises a query on a work order (a question, or "not invoiceable"),
optionally tagging someone in Operations; Operations replies and marks it resolved or not, and Finance is told.
Operations raises questions to Finance the same way. A not-invoiceable query closes only when Operations corrects
the completion it recorded or withdraws its request to invoice (or when Finance closes it). No verification step.

- `finance.query_threads`, `finance.query_comments` (append-only).
- `finance.open_query_thread`, `finance.reply_query_thread`: one transaction each. An open thread puts the work
  order in Query Raised; it goes back when its last open thread ends.
- Copies in the old queries (each with its answer) and the not-invoiceable request still waiting (as an open
  question to Finance); puts a work order with a copied open thread in Query Raised; resolves the stale
  "please verify" notices. The old tables and functions are not changed.

Live-safe: new tables and functions in schema `finance` (nothing on `main` reads it). Idempotent: applying it
twice copies nothing twice (tested on a throwaway Postgres 15 with the old rows).

## Pre-check (expect `f | f`)

```sql
select exists (select 1 from information_schema.tables where table_schema = 'finance' and table_name = 'query_threads'),
       exists (select 1 from pg_proc p join pg_namespace n on n.oid = p.pronamespace where n.nspname = 'finance' and p.proname = 'reply_query_thread');
```

Today's rows it will copy (for comparison after):

```sql
select (select count(*) from finance.line_events where event_type = 'query_raised') as old_queries,
       (select count(*) from finance.wo_exclusions where decision is null) as waiting_requests;
```

## Post-check (expect `t | t | t` and the counts to match the pre-check)

```sql
select exists (select 1 from information_schema.tables where table_schema = 'finance' and table_name = 'query_threads'),
       exists (select 1 from information_schema.tables where table_schema = 'finance' and table_name = 'query_comments'),
       (select count(*) from pg_proc p join pg_namespace n on n.oid = p.pronamespace
          where n.nspname = 'finance' and p.proname in ('open_query_thread', 'reply_query_thread')) = 2;
select (select count(*) from finance.query_threads where legacy_ref like 'query-event:%') as copied_queries,
       (select count(*) from finance.query_threads where legacy_ref like 'exclusion:%') as copied_requests;
```
