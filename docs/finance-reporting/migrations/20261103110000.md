# 20261103110000_finance_fsm_completion_log

Completion sent to Zoho FSM, kept on the work order's history (2 Nov). When Operations marks a line or the whole
work order complete, the portal completes it in FSM too (`lib/server/finance/fsm-completion.ts`, only with
`FINANCE_FSM_COMPLETION=on`). The portal's completion is saved whatever FSM says; FSM's answer, done or why it
refused, is written here.

- `finance.line_events.event_type` also allows `fsm_completed` and `fsm_not_completed`.
- `finance.record_fsm_completion(work order, completed, note, actor, actor label)` writes one such event.

Live-safe: a wider check and one function in schema `finance`. Idempotent (tested on a throwaway Postgres 15).
Until it is applied, FSM's answer is still shown on the page, just not kept on the history.

## Pre-check (expect `f | f`)

```sql
select position('fsm_completed' in pg_get_constraintdef((select oid from pg_constraint where conname = 'line_events_event_type_check'))) > 0,
       exists (select 1 from pg_proc p join pg_namespace n on n.oid = p.pronamespace where n.nspname = 'finance' and p.proname = 'record_fsm_completion');
```
