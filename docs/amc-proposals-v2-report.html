Status

Built, not yet live

Everything the FRD allows to be built is built. It is part-migrated on production and not yet tested end to end.

Thirteen of the fourteen acceptance criteria in §13 are met in code; the fourteenth needs data rather than code. But passing the compiler and the build is not the same as working: every review pass since has found a defect a green build had hidden, and first real use of the Preview buttons found two more (see Found and fixed). Production has four of the five migrations; the client-links migration is still missing, so sending a document to a client will fail until it is applied.

Scope

What was delivered

The FRD replaces v1's pricing model, adds a four-party workflow and moves the standard wording out of the code. It asks, in §9, that the new work follow the snagging quotation — so the approval links, document numbering, audit trail and email all reuse that pattern rather than inventing parallel versions.

Quality

Found and fixed along the way

The honest record. Three defects were in the module before this work began. The rest were introduced during it and caught before release — the last four only because of deliberate checking after the build had passed. That is the case for running the testing guide rather than relying on a green build.

Submissions table open to the public key Customer names, phones and emails readable and editable without signing in Pre-existing
The package kept resetting frequencies A frequency edited to 5 printed as 1 per year — the bug FR4.2 reports Pre-existing

Open

Not fixed, and why

Decide Self-approval is allowed

Anyone with approval rights — and every admin — can approve a proposal they wrote themselves. §9.1 clearly intends a second person, Behrouz, to review the team's work. Blocking it is one line, but it is a policy call: it would also stop Behrouz approving a proposal he wrote himself. Say which you want.

Missing FRD §12

The PDF jumps from §11 to §13. Two requirements cite open issues from the missing section: FR4.8 depends on OI-8, and the "additional fixed price services" section depends on OI-5, which I mapped to clause 6.3 as the FRD suggests but could not confirm.
